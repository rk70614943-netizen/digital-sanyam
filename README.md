# डिजिटल संयम

डिजिटल संयम एक हिंदी Android वेलनेस ऐप है जो फोन उपयोग की आदतों को बेहतर बनाने में मदद करता है।

## CodeAssist में चलाएँ

1. इस रिपॉज़िटरी को डाउनलोड या क्लोन करें।
2. CodeAssist में प्रोजेक्ट का फ़ोल्डर खोलें।
3. Gradle Sync पूरा होने दें।
4. Run दबाएँ।

यह शुरुआती MVP है। इसमें डिजिटल पौधा, स्वस्थ गतिविधियाँ, इच्छा स्तर और CBT-प्रेरित स्थानीय सहायक शामिल हैं।
